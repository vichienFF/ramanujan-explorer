## J1 (Kaggle) zeta(5) delta search
Irrationality of zeta(5) is open. Search Apery-like PCFs (symmetric under n -> -1-n), with m = n^2 + n:
  a(n) = (2n+1)(alpha m^2 + beta m + gamma),  1 <= alpha <= 64, -300 <= beta <= 300, -100 <= gamma <= 100
  b(n) = -s n^10,  s in {1, 2, 4, 8, 16, 32, 64, 128}                                (about 6.2e7 PCFs)
Targets: Mobius transforms (|coeffs| <= 12) of T_k = zeta(5) + k zeta(3), k = -6..6.
Pipeline as batch 1 (float depth 300/600, hash, 50-digit verify, exact reduced convergents, delta at N = 200, 400).
Primary success: a verified PCF to some T_k with delta_200 > 0 AND delta_400 > 0.
Controls before the run: Apery zeta(3) delta ~ 0.08; Cohen's PCF for zeta(5) + 3 zeta(3) (a(n) = n^5+(n-1)^5+6(n^3+(n-1)^3),
b(n) = -n^10, arXiv 2607.06581) evaluated by our delta routine gives the right limit (50 digits) and a stable delta.

Same pipeline and criteria as B2 (G = Catalan; success = delta_200 > 0 and delta_400 > 0). Control: B2 code-path control.

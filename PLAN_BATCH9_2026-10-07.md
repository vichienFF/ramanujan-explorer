# Batch 9 plan (2026-10-07, register before running) - BSD: does a small Szpiro ratio drive the early rank-1 sign change?

Lead (Batch 8, exploratory): the height-family classes all have Szpiro ratio D = log|Delta_min| / log N in [1.00, 1.06];
Cremona median D is 2.40; Cremona's lowest D-deciles give kappa ~0.09 vs ~0.10 for the rest.
Hypothesis H9: rank-1 sign-change scale kappa = p*/sqrt(N) is smaller for curves with D close to 1.
Method as T1/B6-2: log-spaced N-bins, a_p and log L demeaned with log N partialled out within bin, p* = first sign change,
median kappa over bins; bins with < 300 rank-1 curves are skipped; fewer than 5 usable bins = inconclusive.

## B9-1 (local) Cremona, 5e4 <= N < 5e5, EXCLUDING the 33,671 height-family classes (B6-2), 9 bins
P9a: median kappa (rank 1) of classes with D < 1.1 is <= 0.085, and of classes with D >= 1.1 is >= 0.095.
Reported also: dose-response, kappa in D-quintiles of the D >= 1.1 part.

## B9-2 (Kaggle, 1 kernel) independent family with LARGE Szpiro ratio at the T4 conductor range
Quadratic twists: base curves [a1,a2,a3,a4,a6] with a1,a3 in {0,1}, a2 in {-1,0,1}, |a4| <= 60, |a6| <= 400 and base
conductor < 1e5; twist by squarefree d with 2 <= |d| <= 200; minimal model; keep 1e6 <= N < 1e7, analytic rank 0/1
(PARI ellanalyticrank), a_p for p < 1000; dedupe by (N, a_p for the first 30 primes). Same 10 log-spaced bins as T4.
These curves have D well above 1 (twisting multiplies Delta by d^6 and N by about d^2).
P9b: rank-1 median kappa of the twist family >= 0.062 (= 1.5 x the T4 value 0.041 at the same N range).
Reported: D distribution of the twist family; rank-0 results.

Decision: H9 SUPPORTED iff P9a and P9b both hold. Otherwise reported as not supported (or inconclusive per the bin rule).
Controls: shuffle of log L (0 consistent sign changes expected); beta_5 > 0 in every bin; T4 re-analysed with the same code
as reference (must reproduce median kappa 0.041 +- 0.002).

# Batch 20 plan (2026-10-12, register before running) - (A) proof tool for the second mechanism, (B) 18B prevalence rerun

## 20A: rational-lambda coboundary prover for C1, C5, C7, C14 (local, sympy)
Status: C1, C5, C7, C14 equal Mobius transforms of degree-(1,2) PCF limits to 170+ digits (Batches 12-17), but the
polynomial-lambda coboundary (Batch 16: M1(n) U(n) = lambda(n) U(n-1) M2(n - s), lambda = kappa x product of linear factors,
deg U <= 5) finds no proof, and the two-step ansatz (19A) failed its own positive control (void).
New idea: allow lambda to be RATIONAL. Writing lambda = kappa p(n)/q(n) and clearing the denominator gives
     q(n) M1(n) V(n) = kappa p(n) V(n-1) M2(n - s)          (row form; column form as in Batch 16),
still LINEAR in the coefficients of the polynomial matrix V (exact nullspace over Q). Since det gives
lambda^2 = b1(n) det V(n) / (b2(n - s) det V(n-1)) up to the q-factors, p and q are built from linear factors of
b1(n), b2(n - s) and their shifts by -1, 0, +1.
Search box: p = product of 0..3 such factors, q = product of 1..2 such factors (p, q coprime, q not constant),
kappa in +-{1, 2, 3, 4, 6, 8, 9, 12, 16, 18, 24, 27, 36}; s in -3..3; deg V <= 6; row and column forms; every partner form
of each candidate with >= 150 verified digits. Any nullspace solution is checked by expanding the matrix identity
symbolically (= proof of the Mobius relation, as in Batch 16).
Controls (decided before the run; the run is void if a positive control fails):
- Positive 1: C0 must be re-proven (polynomial lambda, inside the box).
- Positive 2 (planted rational lambda, exercises the new code path): from the C0 proof (s = 1, lambda = 2n + 1, deg U = 3)
  take V(n) = (3n + 5) U(n), which gives lambda = (2n + 1)(3n + 5)/(3n + 2) (3n + 2 divides b1 of C0; 3n + 5 is its shift),
  deg V = 4; the solver, run with q restricted to q = 3n + 2, must return this solution (or an equivalent one with non-constant q).
- Negative: C2 paired with a random degree-(1,2) PCF (a = n + 2, b = (2n + 1)(3n + 4)) -> no solution.
Timer standard: per (candidate, partner form, s, form) sub-unit checkpoint to jsonl, time check inside the lambda loop,
local run (sympy; estimated a few hours, detached process), stop at 8 h and report what was covered.
Outcome per candidate: PROVEN (identity verified symbolically) or NOT FOUND IN THIS BOX (not a disproof).

# Batch 11 plan (2026-10-07, register before running) - identifying the 15 candidates, four routes

Status: the 15 limits match none of 21,984 constants (polylogs, Dirichlet L, Clausen, Gamma products, elliptic integrals),
are not Gamma products (150/500 digits), and admit no single-factor Mobius deformation relation (10B-1).
Observation: the dominant singular points are 1/9, 1/10, 1/12, 1/15, 1/16 - typical of Apery-like / sporadic operators
(Domb 1/16, Zagier sporadic 1/9, Almkvist-Zudilin), whose limits are often L-values of MODULAR FORMS, absent from our library.

## 11A (local, PARI) modular-form L-values  [new identification basis; highest priority]
Library: all newforms f of weight 2, 3, 4 and level N <= 100 with rational Fourier coefficients (PARI mfinit/mfeigenbasis,
  trivial or quadratic character), values L(f, s) for integer s in the critical strip and s = 1..4 where defined, at 330
  digits (lfunmf); plus the same divided by pi^j (j = 0..4). About 1-3 thousand constants.
Test per candidate x (1,000-digit values available; use 300): PSLQ [1, x, c, x c] (|coef| <= 1e8) for each c; and
  [1, x, c, x c, pi^2, x pi^2] for c of weight 3, 4 (|coef| <= 1e5). A hit must hold at 300 digits and be re-checked at 600.
Positive control: planted Mobius transforms (3 - 2c)/(5 + 7c) for 5 random library constants -> all recovered.
Negative control: 15 random reals with 300 random digits -> 0 hits.
Success: >= 1 verified hit (then: report, check against literature, add to paper as identification).

## 11B (local, Sage) "breaking the piano": monodromy
For each operator L (15 candidates; controls G1, G2 [factor 1,3], F1 [Euler]) compute numerical monodromy matrices around
all finite singular points from a common base point (ore_algebra numerical_transition_matrix, 120 digits). Test: are the
traces of all words of length <= 4 in the generators algebraic of degree <= 4 (PSLQ minimal polynomial, height <= 1e6)?
Prediction for controls: F1, G1, G2 -> algebraic traces (rigid/hypergeometric components). Candidates: report which are.
Exploratory (no pass/fail); an "algebraic" candidate becomes the next target for a hypergeometric/modular pullback.

## 11C (local) CMF trajectories: two factors shifted together
Same Mobius test as 10B-1 (d <= 4, held-out >= 40 digits) for the direction (t_i, t_j) -> (t_i + k_i m, t_j + k_j m), all
6 pairs per candidate (90 families), m in [-60, 60]. Positive control: Euler family with both h1 and h2 shifted
(h1 = (n+1)(2n+m+3), h2 = 2n(2n+2m+1)) -> ACCEPTED. Negative control: 90 random two-factor families -> <= 4 accepted.
Success: >= 1 candidate family accepted with the negative control <= 4.

## 11D (local, exploratory) "ecosystem": clustering
Features for all 5,274 full-FR PCFs + the 15: characteristic roots, singular points of L, local exponents at the dominant
singularity, convergence rate, irrationality-measure proxy (delta at depth 400). Unsupervised clustering (k-means, 5-40
clusters, silhouette). Report which known/identified PCFs (Conj. 1.3, Euler, Gamma(1/3), Cohen hits) share a cluster with each
candidate -> hypotheses only (any lead needs its own registration). Control: shuffled features give no stable clusters.

Order: 11A, 11C, 11B, 11D. All outcomes reported.

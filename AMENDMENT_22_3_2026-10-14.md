## Step 2'' (local, minutes)
Data: Rokicki-Dogon table as in 22-2. Data control (corrected): L_k equals OEIS A003022 for every 17 <= k <= 28 (else STOP).
Windows: dyadic in N (N in [2^j, 2^{j+1})), j such that each window has >= 5 values of k.
  envelope U_j = max excess in window j; floor F_j = min excess in window j; N_j = geometric window centre.
Models for U_j and F_j separately: bounded, log (a + b ln N), quarter (a N^{1/4}), power (a N^d). Train on windows with
N_j <= 2^{24}, test on the rest (to N ~ 1.6e9). Selection by test RMSE (within 5% -> simpler; order as before).
Controls (each separately for U and F): synthetic bounded / log (b = 1) / power (d = 0.1), noise = resampled residuals of the
selected real fit, 1000 replicates each, must be selected correctly >= 80%; else that quantity is VOID.
Post-hoc check [disclosed, not blind]: the selected envelope model, fitted as above, is compared with the indexp2 b(R) values
for n > 40,000 (6 points); reported as mean signed error, labelled POST-HOC.
Interpretation (stated now): U unbounded (log/power selected) -> evidence that the USD 500 answer is "yes" for the best known
sets; U power with d > 0 -> evidence against #30 (upper side) for those sets; F bounded below by a negative power or sliding to
-infinity -> lower-side evidence; all [INFERENCE about best known sets in a finite range].

## Statement reviewed
r is a prime power, F = GF(r^3), K = GF(r^9), tau(u) = u^r, phi = tau^3, L = ker Tr_{K/F}.
For x in L\{0}, d_x = x/(tau(x) tau^{-1}(x)) and R_x = { y in P(L) : Tr(d_x tau(y) tau^{-1}(y)) = 0 }.
Claim: |R_x| = r+1 if x is not phi-fixed (projectively), and |R_x| = 1 if x is phi-fixed.

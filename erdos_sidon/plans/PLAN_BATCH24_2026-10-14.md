## M - moment method for empty intervals in dilates of Singer sets (Kaggle, 2 kernels)
Code erdos/b24m_moments.py. Z_{t,s} = #{a in S : (t a + s) mod m in [0, l)}, S Singer (|S| = q+1, m = q^2+q+1), l = C q,
C in {2, 4, 6}; all unit classes {+-t} for q <= 61, NT = 4000 random units otherwise; all shifts s.
F_k = mean_{t,s} (Z)_k, k = 1..6; reference H_k = hypergeometric factorial moment (exact for a random (q+1)-subset);
R_k = F_k / H_k - 1. Sets: Singer (q prime in [31, 211] all, [212, 401] every 2nd); null = 4 random (q+1)-subsets per q;
negative control = equispaced set {floor(i m/(q+1))} per q.
G2 simulation done BEFORE registration (random sets and the equispaced set only; no Singer moment was computed): the draft
rule "|R_k| < 0.05" is NOT achievable (random sets: |R_6| up to 0.37 at C = 2 from set-to-set noise), so the rule is:
  Decision rule: for k in {3, 4} and each C, Singer is "random-like at q" if |R_k^Singer(q)| <= the 95th percentile of
  |R_k^null| pooled over the 4 null sets of the same q and its two neighbouring q values. "Moments random-like" if this holds
  for >= 90% of q for every (k in {3, 4}, C). k = 5, 6 reported descriptively only.
  Negative control: the equispaced set must FAIL (random-like for < 50% of q at k = 4, C = 2), else the test is VOID.
  Identity control: the exact k = 2 identity Var_s Z = q l/m (1 - l/m) must hold for every tested t of every Singer set (VERIFIED
  at q = 31 before), else VOID.
Interpretation [INFERENCE]: random-like moments up to order 4 are the numerical precondition for a Bonferroni proof that some
dilate has an empty interval of length C q (=> unbounded excess, Erdos C9 "no"); the proof target is k = 3 for all large q.

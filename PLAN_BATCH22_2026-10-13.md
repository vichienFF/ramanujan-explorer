## 22A: Erdos #30 ($1000) - Sidon sets, h(N) = N^{1/2} + O_eps(N^eps)?
Best upper bound h(N) <= N^{1/2} + 0.98183 N^{1/4} + O(1) (Carter-Hunter-O'Bryant 2025), after Erdos-Turan (1),
Balogh-Furedi-Roy (0.998), O'Bryant 2022. Lower bound (1 - o(1)) N^{1/2} (Singer).
Aim of this batch (a milestone, not the prize): reproduce the optimisation behind the best constant, then attack it with a
larger, computer-searched family of test functions / weights (our addition), aiming at a smaller constant c < 0.98183.
Step 0 (literature, rule 1-5): read CHO25, OB22, BFR21 in full; write down the exact inequality and which parameters were optimised.
Step 1 (positive control): our implementation must reproduce 0.998 (BFR21) and 0.98183 (CHO25) to 4 decimals; if not, STOP and report.
Step 2: enlarge the search space (e.g. more free parameters / piecewise test functions), optimise (LP/convex or global search,
Kaggle CPU), interval-arithmetic verification of any improved constant.
Negative control: the same pipeline applied to a deliberately weakened inequality must not beat its known optimum.
Outcome: IMPROVED (verified c < 0.98183, write-up) / REPRODUCED ONLY / STOPPED AT STEP 1. Exact h(N) data (OEIS A003022 /
Golomb rulers) are used only as a sanity check, not as evidence for the asymptotic statement.

## 22B: Erdos #1049 - is sum_{n>=1} 1/(t^n - 1) irrational for RATIONAL t > 1? (integer t solved)
Our angle: the integer-t proofs use q-Pade approximations; for rational t = a/b the denominators grow too fast. Our expertise is
exactly "factorial reduction" (huge gcd cancellations, Batches 1-21). We measure the q-ANALOGUE of factorial reduction in
Pade-type approximants for rational t: if the effective denominators (after gcd) grow slowly enough relative to the error,
we obtain a numerical irrationality certificate and a concrete structure to prove.
Method: for t in {3/2, 5/2, 4/3, 5/3, 7/2} build Pade-type approximants (q-Pade of the generating Lambert-type series with
q = 1/t, orders n <= 60, exact rational arithmetic), compute p_n/q_n, the gcd-reduced q_n, and
delta_n = -log|x - p_n/q_n| / log|q_n|; irrationality is indicated if delta_n > 1 + eta for all large n (eta fixed 0.05).
Positive control: t = 2 and t = 3 (known irrational) must give delta_n > 1 + eta from some n on.
Negative control: a rational number built from the same family (telescoping sum with the same t, exactly rational) must give
delta_n -> 1 or below (no certificate). Third control: random 60-digit real (no structure) -> no certificate.
Kaggle CPU (exact arithmetic is slow at high order), checkpoint per (t, n). Outcome: CERTIFICATE PATTERN for t / NONE.
A certificate pattern is not a proof; a proof attempt follows only after the pattern is stable and the gcd structure is understood.

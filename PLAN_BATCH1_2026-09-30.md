# Batch 1 plan (2026-09-30, register before running): (1) Catalan delta search, (2) BSD rank-1 slope test

## (1) Catalan's constant G: search for PCFs with positive irrationality exponent delta
Background: irrationality of G is open. An Apery-type proof needs a PCF converging to a Mobius transform of G whose
reduced convergents p_n/q_n satisfy |x - p_n/q_n| = q_n^-(1+delta) with delta > 0 (after factorial reduction).
Search family (Apery-like, symmetric under n -> -1-n), all integers:
  a(n) = (2n+1)(alpha n^2 + alpha n + beta),  1 <= alpha <= 200, -300 <= beta <= 300
  b(n) = -gamma * S(n),  1 <= gamma <= 256,  S in {n^6, n^4(4n^2-1), n^2(4n^2-1)^2, (4n^2-1)^3}
  (about 1.2e8 PCFs; Kaggle, CPU, sharded, checkpoint per unit, no internet, no secrets).
Pipeline: float value at depth 300 vs 600 (converged) -> Mobius hash against G with |coeffs| <= 12 -> verify 50 digits
(mpmath catalan) -> exact integer convergents, reduced by gcd -> delta_N at N = 200 and N = 400.
Primary success: at least one verified G-PCF with delta_200 > 0 AND delta_400 > 0 (then: 1000-digit re-check, literature,
proof attempt). Secondary (always reported): number of distinct G-PCFs found, best delta, delta distribution.
Positive controls before the run: (i) the same code finds a known Catalan PCF and computes its delta consistently at two N;
(ii) the zeta(3) Apery PCF a = (2n+1)(17n^2+17n+5), b = -n^6 (target 6/zeta(3)) gives delta ~ 0.080 (known value).

## Context (decision memo, short)
- [SOURCE Martin-O'Bryant 2004] Erdos C9 ($500, "is R(2,n) = sqrt(n) + O(1)?") is answered NO if Bose(p, theta, 1) has, after a
  suitable dilation, a gap that is not O(p). [SOURCE Green, 100 open problems #32; Shakan 2020] for arbitrary |A| ~ sqrt(p) only
  a gap 2 sqrt(p) is proven. [SOURCE AMS abstract, Zhang Math. Comp. 63 (1994)] Bose-Chowla based lower bounds K(p) for primes
  up to p_145 = 829, e.g. K(p_145) > 10.279 (K = max excess). Full texts of Zhang / Lindstrom: AMS blocks automated access
  (HTTP 403); route A = abstracts only unless the user downloads them manually.
- [INFERENCE] For a Bose set (q marks in Z_m, m = q^2 - 1) cut at a gap G the ruler has excess q - sqrt(m - G) ~ G/(2q); for a
  Singer set (q + 1 marks, m = q^2 + q + 1) the excess is ~ 1/2 + G/(2q). So "G*/q unbounded" (G* = max over dilations of the
  largest gap) implies the C9 answer NO, i.e. the excess is unbounded.

## Route B - computation (Kaggle)
Sets: Bose(q, theta, 1) = {a in [0, q^2 - 2] : theta^a - theta in F_q} for all primes q in [101, 2003] (theta a primitive
element of F_{q^2}); Singer sets for primes q in [31, 211] (F_{q^3}, trace-zero hyperplane). Every set is checked to be Sidon
modulo m (exact) before use.
Statistic: G*(q) = max over multipliers t coprime to m (one representative per class {+-t, +-tq} for Bose) of the largest
cyclic gap of t*A mod m; normalised g*(q) = G*(q)/q; also the distribution (median, 99th percentile) of the largest gap over t.
Null model (control for interpretation): 3 random subsets of Z_m of the same size per q (q in a subsample of 20 primes):
same statistic.
Positive control: the excess implied by G*(829) for the Bose set must be >= 0.9 x 10.279 (Zhang 1994 lower bound), allowing for
Zhang's extra trimming; if not, the pipeline is suspect and the run is VOID.
Registered test (two-way, the only one our data can support - see Amendment 22-3): growth of g*(q) over q, models bounded vs
logarithmic, train q <= 1000, test q > 1000, selection by test RMSE (within 5% -> bounded); controls: synthetic bounded and
synthetic log (b = 1) with resampled residuals, 1000 replicates each, >= 80% correct, else VOID.
Interpretation: log selected -> numerical evidence (finite range) that g* is unbounded for Bose sets, i.e. for the C9 answer NO;
bounded -> evidence the other way; compare with the null model (random sets give g* ~ c log q) [INFERENCE].
Timer standard (5 points): checkpoint per q, batches of multipliers, Kaggle private, no secrets, file list approved before upload;
local timing of the largest q first.

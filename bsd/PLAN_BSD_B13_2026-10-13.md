# BSD B13 plan (2026-10-13, register before running) - the "8th factor": local reduction at 2 and 3

Background (Batches K4-B12C, RESULTS_DIGEST): the rank-1 sign-change scale kappa = p*/sqrt(N) of the slope of a_p against
log L'(E,1) is family-dependent (Cremona 0.104, height family 0.070 at N in [5e4, 5e5); twist 0.076, medium height 0.039 at
N in [1e6, 1e7]). NOT explained by: Tamagawa (H6b), period (H7), torsion and class size (H8), squarefree N / Szpiro ratio
(H8b/c, narrowly), |Delta| ~ N (H9), height growth (P12).
New hypothesis H13: the family effect is carried by the LOCAL REDUCTION TYPES AT p = 2 AND p = 3 (conductor exponents f_2, f_3
and Kodaira types), which none of the tested factors measures directly; small-height curves have atypical 2- and 3-adic structure.
Literature step first (rule 1-5): murmurations (He-Lee-Oliver-Pozdnyakov 2022; Zubrilina 2023; Sutherland; Bober-Booker-Lee-
Lowry-Duda) - check whether a family dependence of rank-conditioned a_p correlations, or a role of 2- and 3-adic local data,
is already known; report before running.

Test (same estimator as B6-2: 9 log-spaced bins in N in [5e4, 5e5), beta_p with log N partialled out, p* = first sign change):
1. compute f_2, f_3 and Kodaira types at 2 and 3 for every curve of both families (PARI ellglobalred / elllocalred);
2. reweight Cremona so that the joint distribution of (f_2, f_3) matches the height family within each N bin (importance
   weights, cells with < 20 curves merged); recompute kappa (median over bins) for rank 1.
Prediction P13: reweighted Cremona kappa within 15% of the height family's 0.070 (from 0.104); stated before running.
Controls: (i) reweighting by an irrelevant variable (class label parity) changes kappa by < 10%; (ii) reweighting by the height
family's own distribution of N within bins only (already matched) changes kappa by < 10%; (iii) shuffle of log L' gives no
consistent sign change; (iv) reproduction of 0.104 and 0.070 before reweighting (+-0.005).
Secondary (exploratory): the same reweighting for the twist family at N in [1e6, 1e7].
Run on Kaggle (PARI via pip, internet ON only for pip; data: Cremona allbsd + ap500 and the height-family output already
produced by K4/B6 runs, uploaded as a private dataset after file-list approval). Checkpoint per family x chunk of curves.

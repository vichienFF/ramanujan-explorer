# Pre-registration: Ramanujan Mode v2 (AI as a discovery tool)

Author: Vichien Fugsukjit (Independent Researcher, Bangkok)
Prepared: 2026-09-28. This file is uploaded to GitHub BEFORE any of the experiments below are run.
Code: `math_explorer/ramanujan/` (explorer.py, verifier.py, bf_search.py, delta_fp.py). Models: free tiers only.

## Background (already observed, not tested here)
- Unguided LLMs mostly rehearse textbook identities (first turn pi in 32/36 sessions); "known" feedback did not help; a random unfamiliar seed helped partially.
- A brute-force polynomial-continued-fraction (PCF) search independently rediscovered published Ramanujan-Machine formulas.
- Goal of v2: use LLMs as a discovery tool the way Ramanujan worked: play with concrete numbers, notice patterns, guess structure; a program verifies.

## E0. Robustness of the "no-claim" behaviour of Nemotron (control experiment)
- Model: nvidia/nemotron-3-ultra-550b-a55b:free (OpenRouter). Same prompt and verifier as the baseline arm.
- Arm E0a: 3 sessions without the `reasoning` request parameter. Arm E0b: 3 sessions with one added sentence: "Making claims is encouraged when you believe something holds."
- Prediction registered now: if mean claims per session stays < 1 in BOTH arms, "no-claim" is treated as a model trait. If mean claims per session >= 3 in E0a, the baseline result is treated as a configuration artefact and reported as such.

## E1. Puzzle numbers ("play with this number")
- Input to the model: one real number given to 30 digits, with no information about its origin, plus the same calculator. Instruction: explore it freely; if you find an exact expression, state it as a claim. 10 turns.
- Calibration set (C, 10 numbers, closed forms known to us, chosen to be non-textbook): Mobius transforms of pi, log 2, zeta(3), Catalan, lemniscate constant, L(2, chi_-3), Gamma(1/3), Gauss constant, pi*sqrt(3), log 5. The list with exact values is fixed in `R2_calibration.json` (created and committed together with this plan).
- Discovery set (D, 10 numbers): limits of fast-converging PCFs from our own search that matched NONE of the 36 reference constants (generated by a fixed script and fixed random seed, file `R2_discovery.json`, committed with this plan).
- Models: gpt-oss-120b, qwen3.8-27b, gemini-3.5-flash (as quota allows), nemotron-3-ultra-550b.
- Primary metric: fraction of C identified exactly (verifier: agreement >= 100 digits and stable at 60/110 digits).
- Registered criteria: a model "can play like Ramanujan" on C if it identifies >= 3/10. Any identification in D verified to 100 digits and 300 digits is a discovery CANDIDATE only; it becomes a claim of novelty only after (i) delta-fingerprint and euler2ai check, (ii) literature search, (iii) independent re-derivation.

## E2. AI + search-engine team (AI chooses directions, the engine searches deeply)
- Each round the model receives a summary of the previous round's verified hits and proposes up to 3 search specifications: degree of a(n), linear factor families for b(n) (k and t ranges), coefficient bound. The engine runs each specification with a fixed compute budget (same number of candidate PCFs per round).
- Baseline (fair comparison, same budget): specifications drawn uniformly at random from the same specification space, same seeds, same number of rounds (8 rounds x 3 specifications).
- 5 paired runs (AI vs random), same verifier and same 36 constants.
- Primary metric: number of distinct verified hits (60 digits) for constants other than pi, sqrt2, sqrt3, phi, e, per 10^8 PCFs evaluated, after removing scale-equivalent duplicates.
- Registered criterion: AI-guided is "better" if its mean primary metric is >= 2x the random baseline AND one-sided paired permutation p < 0.05. Otherwise we report that AI guidance did not help at this budget.
- Secondary: number of discovery candidates whose delta fingerprint matches no known class.

## Rules fixed in advance
- No change of criteria after seeing results. Any deviation is reported explicitly.
- Sessions with rate-limit gaps (>= 2 missing turns) are re-run and the excluded ones are listed.
- No unpublished results, candidate formulas or drafts are sent to any free-tier AI service as input beyond what each protocol above specifies (E1 sends only numbers; E2 sends only our own verified-hit summaries of the current run).
- Heavy local computation avoids 07:10-07:40 (Asia/Bangkok). Kaggle is used only after the author approves the file list.

## Reporting
All results (including null results) are reported with evidence labels: proposed / partial / confirmed.

## C3 - first theorem target of the Erdos C9 moment route: the 1/q coefficient of the 3rd factorial moment
Theory (derived 2026-10-14, [INFERENCE] to be turned into a proof): for a perfect difference set S (|S| = n = q+1, m = n^2-n+1),
averaged over shifts and all unit dilations (m prime case), the 3rd factorial moment of the count in a window of length l is
F_3 = (1/m) sum over ordered triples (a,b,c) of A(rho), rho = (c-a)/(b-a), A(rho) = avg_u W(u, u rho), W = window overlap.
A triple of a perfect difference set can NEVER have rho in {-1, 2, 1/2} (each would repeat a difference); all other rho occur.
If the other ratios occur uniformly, R_3 = F_3/H_3 - 1 = [3 - (A(-1)+A(2)+A(1/2))/Abar]/(m-5), and with A(rho) ~ l^2/(2m) for
these three ratios and Abar ~ l^3/m^2: R_3 ~ -3/(2l) = -3/(2 C q). FIRST-ORDER PREDICTION: c_3(C) = q R_3 = -3/(2C)
(-0.75 at C = 2, -0.375 at C = 4). Measured in Batch 25 (seen): -0.61, -0.28 (ratio to the prediction 0.81, 0.75), so the
first-order term captures the sign and size, and a residual remains (other small-height ratios, e.g. -2, 3, 1/3, -1/2, are
not uniform).

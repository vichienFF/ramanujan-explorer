# Amendment 22-1 to PLAN_BATCH22 (2026-10-13) - 22A redirected: Erdos #30 by the EXPONENT / disproof route

Labels: [VERIFIED] checked by us; [SOURCE] stated by a source (refereed or not, as noted); [INFERENCE] our reasoning; [OPINION].

## Decision memo (why 22A changes; approved by the user before registration)
- [SOURCE, unrefereed forum, erdosproblems.com/forum/thread/30] Since Feb 2026 several groups (incl. AlphaEvolve work of
  Tao et al.; Hou-Zhao arXiv 2607.01169; two Claude-assisted claims) lowered the constant c in h(N) <= N^{1/2} + c N^{1/4}
  from 0.98183 (CHO25, refereed) to a claimed 0.9428; one author states the framework cannot go below about 0.9428 AND cannot
  improve the exponent 1/4.
- [INFERENCE] The $1000 statement asks h(N) = N^{1/2} + O_eps(N^eps) for EVERY eps > 0, i.e. an exponent below 1/4 (proof) or
  a growing power excess (disproof). Improving c cannot reach the prize statement in either direction. So the constant race is
  not the prize route; the original 22A (improve c) is withdrawn for that reason - NOT because the problem is closed.
- What would make this wrong: if a constant-type argument were known to iterate into an exponent gain, or if the prize terms
  were different. Both are checked in Step 0.
- [SOURCE, erdosproblems.com/30] Erdos remarked that h(N) = N^{1/2} + O(1) is "perhaps too optimistic"; the page does not say
  whether the $1000 is for a proof, a disproof, or either (to be checked in Step 0).
- [SOURCE, forum 9 Aug 2026, unrefereed] exact h(N) up to N = 586 (optimal Golomb rulers, OEIS A143824) shows h(N) - sqrt(N)
  still growing over that range. [SOURCE, Wikipedia / distributed.net] optimal Golomb rulers are proven up to 28 marks (OGR-28,
  Nov 2022). [SOURCE, Dimitromanolakis 2002 thesis] near-optimal rulers (length < n^2) up to 65,000 marks from Singer/Bose.

## Step 1 - excess analysis on exact and best-known data (local, minutes)
e(N) = h(N) - sqrt(N) from exact h(N) (N <= 586) and lower bounds L(N) from best-known rulers (larger N, label: lower bound only).
Fit three models on N in [50, 586]: bounded (e -> const), logarithmic (a + b log N), power (a N^delta); compare by held-out
error (fit on N <= 400, predict 401..586). Controls: (i) synthetic data from a bounded-excess model with the same noise
structure must select "bounded"; (ii) synthetic power excess (delta = 0.1) must select "power"; if either control fails the
model comparison is void. Output is EVIDENCE about finite ranges only [INFERENCE], never a claim about the limit.

## Step 2 - construction search for large Sidon sets beyond 28 marks (Kaggle)
Goal: for N in [600, 6000], Sidon sets in [1, N] LARGER than the best of (a) all modular dilations/translations/truncations of
Singer, Bose and Ruzsa sets (our baseline, computed exactly) and (b) published near-optimal rulers where available.
Method (different from exhaustive OGR search): local search (tabu / simulated annealing with exact difference bookkeeping),
seeded from algebraic sets AND from random sets; every reported set is verified exactly (all pairwise differences distinct).
Positive control: recover the known optimal sizes for k <= 16 marks (lengths from the OGR table) within the time budget.
Negative control: on a toy universe where the maximum is known by exhaustive search (N <= 150), never report a size above it.
Timer standard (5 points), checkpoint per N, private Kaggle, no secrets, file list approved before upload.
Outcome: NEW RECORD sets (verified) or NO IMPROVEMENT over the baseline; the excess of the best sets feeds Step 1.

## Step 3 - exponent route, exploratory (local)
Use exact optimal sets (k <= 28) as a laboratory: compare their difference structure (gap and difference-multiplicity
statistics in sub-intervals) with what the Erdos-Turan / Lindstrom counting argument uses, to locate where the N^{1/4} loss
arises. Output: [INFERENCE] notes and candidate inequalities only; any candidate inequality is tested numerically on all exact
data before it is called a conjecture.

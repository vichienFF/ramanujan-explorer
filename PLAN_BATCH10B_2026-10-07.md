# Batch 10B plan (2026-10-07, register before running) - "input -> output": deform the 15 candidates

Idea: a single limit x is hard to identify; a FAMILY x(m), obtained by shifting one integer parameter m, carries structure.
If the 15 PCFs sit inside a conservative matrix field (CMF) or a hypergeometric family, consecutive members are linked by a
Mobius map with polynomial coefficients in m:   A(m) + B(m) x(m) + C(m) x(m+1) + D(m) x(m) x(m+1) = 0   (*)
Finding (*) would place a candidate in a known type of structure and give a route to identification.

Families: for each candidate C0..C14 with b(n) = s * prod_{i=1..4} (k_i n + t_i), and each i = 1..4, the direction
t_i -> t_i + m, m in [-25, 25] (a(n) unchanged). 60 families. Values of m where b(n) = 0 for some n >= 1 (terminating CF)
or where fewer than 80 correct digits are reached (exact recurrence, depth chosen adaptively up to 6,000) are skipped.
Test: for d = 1..4 (degree of A, B, C, D in m), solve for the coefficients by least squares / null space at 80 digits on the
first 4(d+1) + 8 usable consecutive pairs (m, m+1); a relation is ACCEPTED if the smallest singular value is < 1e-60 times
the largest, the next one is > 1e-20 times the largest, and the relation predicts x(m+1) from x(m) to >= 40 digits on
>= 10 held-out pairs. Smallest d reported.
Positive control: an Euler-type family a(n) = h1(n) + h2(n+1), b(n) = -h1(n) h2(n) with h1(n) = (n + 1)(n + m + 2),
  h2(n) = n (2n + 1) (its limit is a hypergeometric sum in m, so (*) must hold by creative telescoping) -> must be ACCEPTED.
Negative control: 15 PCFs with the same a(n) shapes and random b(n) = s prod (k_i n + t_i) WITHOUT factorial reduction,
  same 4 directions (60 families) -> expected 0 accepted (if > 3 accepted, the test is not discriminating and hits are void).
Success (exploratory but decisive for follow-up): >= 1 candidate family accepted while the negative control gives <= 3.
Every accepted relation is then reported with its polynomials and checked by hand against known CMFs (pFq, zeta3 field).
Run locally if < 30 min, else Kaggle (agreed rule). All outcomes reported.

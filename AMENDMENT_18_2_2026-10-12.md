# Amendment 18-2 to PLAN_BATCH18 (68ec9b5) - fix of the re-check evaluator for the C12 completion run

Facts (local run of 2026-10-12, CFG=wide, targets C12 + control C5, under Amendment 18-1 (1)):
- C12: 77 float matches, 0 confirmed, 77 logged as "slow partners". The control C5 never finished (the WSL process stopped
  after C12 without an error message). The float matches themselves were not saved (only their count).
- Cause found: the capped re-check evaluator (b10b1_deform.limit_value, added after Kaggle lesson 2026-10-09) computes at
  90 + 20 = 110 digits. The wide setting asks for 160 digits, so the condition could never be met and EVERY partner was
  logged slow. Check: on 1 + 1/(3 + 4/(5 + 9/...)) = 4/pi it returns "no value" at need = 160.
  Hence "0 confirmed" for C12 is VOID (not a negative result). Runs that used the uncapped deep_id.cf evaluator
  (Batches 17, 18A on Kaggle, 18B partial) are not affected.

Changes (only the re-check step; the float search, the Mobius table, the parameter grid and the decision rules are unchanged):
(1) New evaluator limit_mp in b18_mechanism.py: forward recurrence in mpmath at need + 30 digits, values at depths
    1000, 2000, 4000, ... up to 64,000; a value is accepted when two consecutive depths agree to `need` digits.
    Tool check before the run (done 2026-10-12): 4/pi PCF -> 190 digits correct; Brouncker's PCF (known to converge only
    like 1/n) -> correctly reported "slow"; the known C5 partner a = 6n - 3, b = 9(3n - 2)(5n - 2) -> 190 digits.
(2) Every float match is now written to the output (partner a, b, Mobius map, and the digits reached if slow).
(3) Rerun C12 and C5 with CFG=wide, locally (Windows Python, detached process; estimated about 1 hour).

Decision rules (stated before the run):
- Control: the run is valid only if C5 is confirmed through its known partner (y = (x - 3)/(-4 - x) with a = 6n - 3).
  If C5 is not confirmed, the C12 result is void.
- C12 counts as IDENTIFIED only if a partner is confirmed at >= 145 digits AND an independent check (deep_id.cf, 170+ digits)
  agrees; the paper's count then changes from 7/8 to 8/7.
- If no partner is confirmed and no partner is left slow: "no degree-(1,2) partner in the wide grid" (negative within the grid).
- If no partner is confirmed but some partners stay slow: reported as INCOMPLETE with their list (no claim either way).

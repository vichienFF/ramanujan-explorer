# Batch 8 plan (2026-10-07, register before running) - BSD: why the sign-change scale depends on the family

Facts used: a_p and L^(r)(E,1) are isogeny invariants, so beta_p depends only on WHICH isogeny classes are in the sample,
not on the representative curve. Every height-family class with N < 5e5 (B6-2) is also a Cremona class.
B6-2/B7-2: rank-1 median kappa Cremona 0.104 vs height 0.070 at equal N; Tamagawa (H6b) and Omega (H7) do not explain it.

Method (all local, Cremona data + B6-2 output): 9 log-spaced N-bins in [5e4, 5e5); beta_p with log N partialled out within bin;
p* = first sign change; kappa = p*/sqrt(N_mid); median over bins, rank 1 (rank 0 reported).
Class features (from the Cremona curve-1 model): T = torsion order > 1, S = N squarefree, D = Szpiro ratio
log|Delta_min| / log N (tercile within bin), K = number of curves in the isogeny class > 1.

H8a (consistency check): Cremona restricted to the classes present in the height family (matched by N and a_p, p < 500)
     gives median kappa within 10% of the height family's own value.
H8b (feature strata): kappa computed in Cremona separately for T, S, D-tercile and K strata. Prediction: at least one
     feature has a stratum with median kappa within 25% of the height value (0.070) while its complement stays within 25%
     of 0.104; reported for all four features.
H8c (reweighting): Cremona reweighted (cell weights over the joint cells of T x S x D-tercile x K) to match the height
     family's cell distribution has median kappa within 25% of 0.070 (weighted least squares in each bin).
Controls: shuffle of log L (0 consistent sign changes); beta_5 > 0 in every bin; H8a itself acts as the identity control.
Outcomes of all parts are reported; a confirmed explanation requires a new registration on independent data (e.g. N in 5e5-1e6).

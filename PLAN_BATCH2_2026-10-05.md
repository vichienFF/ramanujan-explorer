## (2) BSD H4: rank-1 sign-change scaling law (fresh data computed by us)
Exploration on the discovery set (N < 250,000) showed that for rank-1 classes the slope beta_p of a_p on log L'(E,1)
first changes sign at a prime p* that grows with the conductor: p* = 19, 31, 47 for sqrt(N) ~ 158, 295, 433, i.e.
kappa = p*/sqrt(N) ~ 0.11. (Disclosure: the pooled held-out H3 run, N 250k-500k, showed a sign change near p ~ 61,
consistent with kappa ~ 0.10; that set is therefore NOT used for H4.)
Fresh test data: curves we compute with SageMath/PARI (local WSL), Weierstrass coefficients enumerated in a fixed box,
conductor 600,000 <= N < 2,000,000, analytic rank 1, with L'(E,1) and a_p (p < 200) from PARI; target >= 20,000 classes.
Split into conductor bins [0.6M, 1.0M), [1.0M, 1.5M), [1.5M, 2.0M). Same within-bin estimator as H3.
H4 SUPPORTED iff in every bin with >= 4,000 classes the first prime where beta_p changes from > 0 to <= 0 satisfies
0.08 <= p*/sqrt(N_mid) <= 0.14, AND p* increases from the lowest to the highest bin. Otherwise REJECTED.
Novelty to be checked (approximate functional equation scale sqrt(N); Wachs arXiv 2603.22807) before any claim.

# Batch 21 plan (2026-10-13, register before running) - (A) close C12's last partner, (B) mechanism-guided search for the eight

Context: preprint v3 (DOI 10.5281/zenodo.23337496). All seven identified candidates are proven by coboundaries
M1(n) V(n) = lambda(n) V(n-1) M2(n - s), lambda = (1, 1/2 or 1/3) x one linear factor of the candidate's b; the partner's b is
a scalar times two other linear factors of the candidate's b, EACH shifted by an integer (C1: both by -3; C14: one by +2, the
other by -1). The Batch-18 filter used one common shift |s| <= 2, so it could not reach C1 or C14.
Observation from the seven proofs (checked 2026-10-13 for all seven): with A = lead(a1), B = lead(b1), the partner satisfies
  alpha^2 / lead(b2) = A^2 / B      (alpha = lead(a2)),
i.e. the characteristic roots of candidate and partner have the same ratio, as a polynomial gauge with linear lambda implies.

## 21A: the unresolved C12 partner (local, minutes)
Partner a = 14n - 7, b = -54n^2 + 261n - 81, Mobius (-6, -8, 8, -7) from the Amendment 18-2 rerun (10 digits at depth 64,000).
Characteristic roots of t^2 - 14t + 54 are 7 +- i sqrt(5) (equal modulus): for real coefficients the two asymptotic solutions
are complex conjugates of equal size, so P_n/Q_n is expected to oscillate without a limit.
Pilot observation (disclosed; made while writing this plan, 2026-10-13): values at depths 1,000-100,001 stay in a band of
width ~4e-11 around 1.18741203954 without shrinking, while the Mobius prediction from C12 is 1.18741203136 (8e-9 away).
Test: values at 200 depths between 10^3 and 10^6 (mpmath, 60 digits); band = [min, max] over depths >= 10^4.
Decision: REJECTED if the prediction lies outside the band widened by 10x its width; CONFIRMED only if the band shrinks
(width at 10^6 < 1e-3 x width at 10^4) AND the prediction is inside it; otherwise UNRESOLVED.
Controls: (i) convergent hyperbolic PCF a = 2n + 1, b = n^2 (limit 4/pi): band must shrink below 1e-50;
(ii) elliptic-case PCF a = 2n + 1, b = -2n^2: band must NOT shrink (expected oscillation).
If 21A rejects the partner, C12 has "no degree-(1,2) partner in the Batch-18 wide grid" (negative within that grid).

## 21B: mechanism-guided filter for C2, C3, C4, C6, C8, C9, C12, C13 (Kaggle)
Partners: b2(n) = kappa x (k1 (n + s1) + t1)(k2 (n + s2) + t2) for every pair of linear factors (k n + t) of the candidate's b,
INDEPENDENT shifts s1, s2 in -6..6; kappa in +-{1,2,3,4,6,8,9,12,16,18,24,25,27,32,36,48,49,50,64,72,81,100,144};
alpha FIXED by alpha^2 = lead(b2) A^2 / B (both signs not needed: alpha > 0); if alpha = u/d is rational with d in {2, 3}
the integer-normalised partner a2 = u n + beta', b2 -> d^2 b2 is used; if alpha is irrational the (pair, kappa) is skipped;
|beta| <= 1000 (|beta'| <= 3000 for d = 3); Mobius coefficients |p|, |q|, |r|, |s| <= 12 (was 8).
Float match (depth 600 / 1200) then 160-digit re-check with the Amendment 18-2 evaluator; every float hit is saved.
Confirmed matches (>= 145 digits) are re-checked to 300 digits by an independent evaluator and passed to the rational-lambda
prover (b20_rational.py, Amendment 20-1 box with shifts -6..6).
Scope note: the alpha condition restricts the search to the proven mechanism (linear lambda); a partner related in another way
would not be found. This is the price of widening the shifts and the Mobius range at an affordable cost.
Controls (run first; the run is void if a positive control fails):
 - positive: C0, C1, C5, C7, C14 must each be re-found (C1 and C14 are reachable only through the new independent shifts);
 - negative: two random reals (seeded, 160 digits) in place of x, with the b of C2 and of C12 -> 0 confirmed matches.
Timer standard (5 points): sub-units = (target, pair, s1) with jsonl checkpoint; time check inside the kappa loop; capped
depths with "slow" logged; local timing of the slowest target before upload, shard size for <= 8 h per kernel; continuation
rounds through kernel_sources. Kaggle: private, no internet, no secrets; the file list is shown for approval before upload.
Outcome per candidate: IDENTIFIED (160 + 300 digits, plus proof if found) or NOT FOUND IN THIS GRID (not a proof of novelty).
If any of the eight is identified, the paper is updated (v4) and the counts change accordingly.
